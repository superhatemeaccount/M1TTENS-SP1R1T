M1TTENS SP1R1T - setup

1. Put the Stockfish files in this folder, next to manifest.json:
     stockfish-19-lite-single.js
     stockfish-19-lite-single.wasm
   (from C:\Users\cheez\node_modules\stockfish\bin\ , don't rename them)
2. Opera GX -> opera://extensions -> Developer mode ON -> Load unpacked -> pick this folder.
3. Go to chess.com/play/coach (or /play/computer) and start a game.
